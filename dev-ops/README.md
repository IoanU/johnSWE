# DevOps

Hands-on resources for operating software reliably: Linux troubleshooting, containers, orchestration, automation, and production workflows.

## Resources

| Resource | Best for |
| --- | --- |
| [SadServers](https://sadservers.com/) | Live Linux and DevOps troubleshooting scenarios - essentially "LeetCode for Linux/DevOps." |
| [Docker - Get Started](https://docs.docker.com/get-started/) | Official, free introduction to containers, images, Dockerfiles, and container workflows. |
| [Kubernetes Basics](https://kubernetes.io/docs/tutorials/kubernetes-basics/) | Official tutorial covering deployment, scaling, updates, and debugging of containerized applications. |
| [Pro Git](https://git-scm.com/book/en/v2) | The complete Git book, available free online. Useful far beyond basic Git commands. |
