# Agentic AI

Resources for understanding AI agents, tool use, agent workflows, evaluation, and practical agent frameworks.

## Resources

| Resource | Best for |
| --- | --- |
| [Hugging Face Agents Course](https://huggingface.co/learn/agents-course/en/unit0/introduction) | A free, hands-on course that goes from agent fundamentals to frameworks, agentic RAG, evaluation, and a final project. |
| [LangGraph Documentation](https://langchain-ai.github.io/langgraph/) | Learning how to build stateful, controllable agent workflows and graphs. |
| [Microsoft AutoGen](https://microsoft.github.io/autogen/) | Exploring event-driven and multi-agent application patterns with an open-source framework. |
| [Agent Skills](https://agentskills.io/) | Learn how to create, structure, and use reusable skills that extend agent capabilities. Includes the specification, guides, and best practices. |
| [Claude Code](https://code.claude.com/docs/en/overview) | Official Claude Code documentation covering skills, commands, subagents, hooks, MCP, permissions, memory, automation, and extensibility. |
| [Microsoft Agent Framework](https://learn.microsoft.com/en-us/agent-framework/) | Microsoft's complete learning hub for agents, workflows, tools, memory, skills, agent harnesses, orchestration, security, integrations, and hosting. |
| [OpenAI Agents SDK](https://openai.github.io/openai-agents-js/) | Official OpenAI Agents SDK documentation covering agents, tools, handoffs, guardrails, orchestration, tracing, realtime agents, and other agent primitives. |
| [Anthropic Engineering](https://www.anthropic.com/engineering) | Anthropic's engineering hub with in-depth articles on building effective agents, agent architectures, context engineering, evaluations, tool use, and production agent systems. |

## What to learn first

Before going deep into frameworks, make sure you understand the basic loop behind an agent: **model → tool/action → observation → next decision**. Framework APIs change quickly; the underlying architecture matters more.
