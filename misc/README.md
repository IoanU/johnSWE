# Miscellaneous

A temporary home for useful software-engineering resources that do not yet have a dedicated category.

## Resources

| Resource | Best for |
| --- | --- |
| [The Missing Semester of Your CS Education](https://missing.csail.mit.edu/) | Practical tools that traditional CS courses often skip: shell, editors, Git, debugging, profiling, metaprogramming, and security. |
| [DevDocs](https://devdocs.io/) | Fast, searchable documentation for many languages and libraries in one interface. |
| [ISE Engineering Fundamentals Playbook](https://microsoft.github.io/code-with-engineering-playbook/) | How to work as an engineer: code reviews, source control, testing, CI/CD, documentation, design reviews, observability, security, Agile, DevEx and repo conventions. |
| [Google Style Guides](https://google.github.io/styleguide/) | Actual conventions for C++, Java, Python, Go, TypeScript, JavaScript, HTML/CSS, Markdown, Shell. |
