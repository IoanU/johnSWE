# Cybersecurity

Resources for learning application security through clear explanations, structured methodology, and safe hands-on practice.

## Resources

| Resource | Best for |
| --- | --- |
| [Hacksplaining](https://www.hacksplaining.com/) | Clear explanations and interactive examples of common web vulnerabilities; free for personal use. |
| [PortSwigger Web Security Academy](https://portswigger.net/web-security) | Free, high-quality web-security learning paths and hands-on labs covering modern vulnerability classes. |
| [OWASP Web Security Testing Guide](https://owasp.org/www-project-web-security-testing-guide/stable/) | A comprehensive, open-source methodology for testing web applications and services. |
| [OWASP Cheat Sheet Series](https://cheatsheetseries.owasp.org/) | A concise collection of high value information on specific application security topics. |

## Suggested path

Learn the vulnerability class first, reproduce it only in an authorized lab, then read the OWASP methodology to understand how professionals test for it systematically.

> [!IMPORTANT]
> Practice only on systems you own or have explicit permission to test.
