# QA & Testing

Free resources for learning software testing as an engineering discipline: test design, automation, reliability, and practical debugging.

## Resources

| Resource | Best for |
| --- | --- |
| [Test Automation University](https://testautomationu.applitools.com/) | Free courses on test automation, browser testing, API testing, CI, and many common testing tools. |
| [Playwright Documentation](https://playwright.dev/docs/intro) | Official guide for modern end-to-end browser automation, fixtures, assertions, parallelism, tracing, and debugging. |
| [pytest Documentation](https://docs.pytest.org/en/stable/) | Official reference and examples for Python testing, fixtures, parametrization, plugins, and test organization. |
| [Google Testing Blog](https://testing.googleblog.com/) | Engineering articles about testability, test design, reliability, and testing practices at scale. |

## Core topics

Learn the testing pyramid, unit/integration/E2E boundaries, deterministic tests, mocking vs. real dependencies, fixtures, test isolation, flaky-test debugging, API testing, browser automation, CI integration, and how to write useful failure reports.
