# Databases

Resources for learning both sides of databases: **how to use them well** and **how database systems work internally**.

## Resources

| Resource | Best for |
| --- | --- |
| [SQLBolt](https://sqlbolt.com/) | Learning SQL syntax through short explanations and interactive exercises. |
| [Use The Index, Luke!](https://use-the-index-luke.com/) | Understanding SQL indexing and query performance from an application developer's perspective. |

## Suggested path

1. Get comfortable writing SQL.
2. Learn relational modeling, constraints, indexes, and transactions.
3. Study database internals once you want to understand *why* a query or system behaves the way it does.
