# APIs

Resources for designing, building, and reasoning about APIs — from HTTP fundamentals to protocol choices, rate limiting, versioning, and security.

## Resources

| Resource | Best for |
| --- | --- |
| [API Cheatsheet](https://168hd5iyr2czx.space.minimax.io/) | A compact overview spanning protocol selection, rate limiting, API security, and other common design concerns. |
| [MDN — HTTP](https://developer.mozilla.org/en-US/docs/Web/HTTP) | The authoritative practical reference for HTTP methods, headers, status codes, caching, cookies, CORS, and related web concepts. |
| [Microsoft REST API Guidelines](https://github.com/microsoft/api-guidelines) | Real-world conventions and design guidance for consistent REST APIs. |

## Focus areas

A strong API foundation should cover **HTTP semantics**, authentication and authorization, idempotency, pagination, validation, versioning, rate limiting, caching, observability, and backwards compatibility.
