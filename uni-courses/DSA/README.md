# Data Structures & Algorithms

Visual, interactive, and practice-first resources for building intuition for data structures, algorithms, and common problem-solving patterns.

## Resources

| Resource | Description |
|---|---|
| [VisuAlgo](https://visualgo.net/) | One of the best ways to *see* data structures and algorithms execute. Step through graphs, trees, heaps, sorting, dynamic programming, and more with animations and custom inputs. |
| [Codewars](https://www.codewars.com/) | Solve bite-sized programming kata directly in the browser, get instant feedback, level up through ranks, and compare your solution with other approaches. |
| [HackerRank — Algorithms](https://www.hackerrank.com/domains/algorithms) | Browser-based algorithm challenges with automatic judging, useful for drilling individual topics and getting comfortable coding under constraints. |
| [DSA Roadmap](https://roadmap.sh/datastructures-and-algorithms) | A visual checklist of the main DSA topics and a useful map for spotting gaps in your knowledge. |

## Core concepts to understand

- arrays, strings, hash tables, linked lists
- stacks, queues, heaps, and priority queues
- trees, BSTs, tries, and graphs
- sorting and binary search
- recursion and backtracking
- BFS and DFS
- greedy algorithms
- prefix sums, sliding window, and two pointers
- dynamic programming
- union-find / disjoint sets
- shortest paths and minimum spanning trees
- time and space complexity

## A good learning loop

`Visualize the idea` → `Implement it yourself` → `Solve a few pattern-based problems` → `Explain why the complexity is correct`
