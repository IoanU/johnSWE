# Computer Networks

Hands-on resources for understanding what actually happens between typing a URL and receiving a response.

## Resources

| Resource | Description |
|---|---|
| [Cisco Skills for All](https://skillsforall.com/catalog) | Free networking courses with interactive activities and Packet Tracer-based labs. A great structured entry point for networking fundamentals. |
| [Cisco Packet Tracer](https://skillsforall.com/topics/cisco-packet-tracer) | Build virtual networks, connect routers and switches, configure protocols, and watch packets move without needing physical hardware. |
| [Chrome DevTools — Network](https://developer.chrome.com/docs/devtools/network) | Learn networking through traffic from real websites: inspect requests, headers, payloads, redirects, timing, caching, and connection behavior directly in the browser. |
| [Cloudflare Learning Center - Network Layer](https://www.cloudflare.com/learning/network-layer/what-is-the-network-layer/) | Modern, approachable explanations of IP, routing, packets, TCP/UDP, DNS, HTTP, TLS, DDoS, and related Internet infrastructure. |
| [Networking fundamentals](https://youtube.com/playlist?list=PLIFyRwBY_4bRLmKfP1KnZA6rZbRHtxmXi&si=GfVdom849279_Lyg) | The ultimate video series which will teach you the core of Networking: How data flows through the Internet. |

## Core concepts to understand

- OSI vs. TCP/IP models
- Ethernet, MAC addresses, and ARP
- IPv4 / IPv6 and subnetting
- routing and default gateways
- TCP vs. UDP
- ports and sockets
- DNS
- HTTP and HTTPS
- TLS
- DHCP
- NAT
- proxies, reverse proxies, and load balancers
- firewalls
- latency, bandwidth, packet loss, and congestion
- packet capture and traffic analysis

## Suggested approach

`Packet Tracer` → `IP + routing` → `TCP/UDP` → `DNS` → `HTTP/TLS` → `inspect real browser traffic`
