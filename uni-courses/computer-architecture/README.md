# Computer Architecture

Interactive resources for going from logic gates to instructions, pipelines, caches, and real CPU execution.

## Resources

| Resource | Description |
|---|---|
| [Ershov Computer](https://ershovcomputer.ru/en/) | Build an 8-bit computer interactively from logic gates upward, then run programs on the machine you assembled. No installation or account required. |
| [SonicRV](https://sonic-rv.ics.jku.at/) | Browser-based RISC-V visualization covering single-cycle, multi-cycle, and pipelined CPU execution. |
| [Nand2Tetris Web IDE](https://nand2tetris.github.io/web-ide/) | Build a computer stack from NAND gates through a CPU, assembler, VM, and higher-level software using browser-based tools. |

## Core concepts to understand

- binary representation and Boolean logic
- gates, adders, multiplexers, and ALUs
- registers and sequential logic
- instruction set architectures
- assembly and machine code
- datapath and control unit
- stack vs. registers
- memory hierarchy
- caches and locality
- virtual memory basics
- pipelining
- data, control, and structural hazards
- branch prediction
- interrupts and I/O
- multicore architecture and cache coherence

## Suggested path

`Logic gates` → `ALU + registers` → `ISA + assembly` → `CPU datapath` → `pipeline` → `caches + memory hierarchy`
