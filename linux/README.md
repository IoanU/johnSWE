# Linux

Resources for becoming comfortable with Linux as a development and production environment rather than only memorizing shell commands.

## Resources

| Resource | Best for |
| --- | --- |
| [SadServers](https://sadservers.com/) | Hands-on Linux troubleshooting on live servers — “LeetCode for Linux/DevOps.” |
| [The Linux Command Line](https://linuxcommand.org/tlcl.php) | A free book covering shell usage, commands, scripting, permissions, processes, and common tools. |
| [Linux Journey](https://linuxjourney.com/) | Friendly lessons covering the command line, permissions, processes, networking, filesystems, and related fundamentals. |
| [Killercoda — Linux](https://killercoda.com/linux) | Free browser-based Linux environments for experimenting with processes, filesystems, permissions, networking, and system tools. |

## Focus areas

Files and permissions, processes, signals, file descriptors, pipes, networking, services, logs, package management, shell scripting, filesystems, memory, and basic performance/debugging tools are the highest-value topics.
