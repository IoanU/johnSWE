# Frontend

A mix of fundamentals, visual inspiration, interaction libraries, and tools for building polished web interfaces.

## Learn the fundamentals

| Resource | Best for |
| --- | --- |
| [MDN — Learn Web Development](https://developer.mozilla.org/en-US/docs/Learn_web_development) | Structured HTML, CSS, JavaScript, accessibility, and frontend fundamentals. |
| [Full Stack Open](https://fullstackopen.com/en/) | A free, university-backed deep dive into modern React, TypeScript, Node.js, APIs, testing, and related tooling. |

## Design inspiration

| Resource | Best for |
| --- | --- |
| [Refero](https://refero.design/) | Browsing real UI patterns and product-design references. |
| [MotionSites](https://motionsites.ai/) | Animation-heavy landing-page inspiration and code examples; free selection is limited. |
| [Pinterest](https://www.pinterest.com/) | Broad visual inspiration when you search for specific UI patterns such as “developer portfolio hero” or “SaaS pricing page.” |

## Design generation

| Resource | Best for |
| --- | --- |
| [Google Stitch](https://stitch.withgoogle.com/) | Prompt-based UI generation and templates. It has a free limited quota. |

## Animation

| Resource | Best for |
| --- | --- |
| [Anime.js](https://animejs.com/) | Lightweight JavaScript animation primitives. |
| [Motion](https://motion.dev/) | Production-ready web animations, especially useful with modern frontend frameworks. |

## Charts & data visuals

| Resource | Best for |
| --- | --- |
| [Bklit](https://bklit.com/) | Inspiration and examples for charts and data-driven interfaces. |
| [Observable Plot](https://observablehq.com/plot/) | Free, open-source JavaScript library for concise exploratory data visualization. |
