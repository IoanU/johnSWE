# CV Maxxing

Resources for strengthening a software-engineering CV through **real skills, credible certificates, and projects worth discussing in interviews**.

The goal is not to collect badges. Prioritize evidence that you can build, debug, ship, explain, and improve technical work.

## Guides

| Area | Guide |
| --- | --- |
| Certificates | [Free and useful certificate/course sources](certificates/README.md) |
| Projects | [Project-based learning and portfolio ideas](projects/README.md) |

## What usually has the strongest signal

1. Relevant work or internship experience.
2. Strong projects with clear technical depth and measurable outcomes.
3. Competitions, open-source contributions, research, or meaningful community work.
4. Certificates that validate a skill the rest of your profile already supports.
