# Certificates

Places to find courses and credentials that can support a technical CV — especially when they reinforce skills you can also demonstrate through projects or experience.

## Resources

| Resource | Notes |
| --- | --- |
| [Cisco Networking Academy](https://www.netacad.com/) | Free courses are available across networking, cybersecurity, Python, Linux, and related topics; availability can vary by course. |
| [Class Central](https://www.classcentral.com/) | Excellent discovery engine for courses from universities and major learning platforms. Always check whether the **certificate itself** is free, because many courses are free to learn but charge for certification. |
| [freeCodeCamp](https://www.freecodecamp.org/learn/) | Free, project-based certifications covering web development, JavaScript, Python, data, security, and more. |
| [Hugging Face Agents Course](https://huggingface.co/learn/agents-course/en/unit0/introduction) | Free agentic-AI course with certificate milestones tied to course completion. |
| [IBM Data Science Professional Certificate](https://www.coursera.org/professional-certificates/ibm-data-science) | Useful curriculum, but Coursera's certificate access is generally not guaranteed to be free. Keep it only if the cost/access model works for you. |

## Rule of thumb

A certificate is most useful when an interviewer can ask “what did you build or learn from this?” and you have a concrete answer. Avoid collecting certificates only to fill space.
