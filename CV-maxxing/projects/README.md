# Projects

Resources for finding project ideas that force you to build something real instead of following isolated syntax tutorials.

## Resources

| Resource | Best for |
| --- | --- |
| [Project Based Learning](https://github.com/practical-tutorials/project-based-learning) | A large collection of tutorials where you learn by building complete applications and systems from scratch. |
| [Build Your Own X](https://github.com/codecrafters-io/build-your-own-x) | Reimplementing databases, shells, web servers, Git, containers, compilers, and other systems to understand how they work internally. |

## What makes a project strong

Prefer projects with at least one non-trivial engineering dimension: concurrency, networking, systems work, performance, security, distributed state, real users, deployment, testing, observability, or a meaningful data/ML pipeline.

The README of the project matters too: explain the problem, architecture, trade-offs, setup, screenshots/demo, and what you would improve next.
