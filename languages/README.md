# Programming Languages

General resources for becoming fluent in a language, plus focused guides for the languages currently covered by this repository.

## General practice

| Resource | Best for |
| --- | --- |
| [Exercism](https://exercism.org/) | Free exercises, tracks, and community mentoring across dozens of programming languages. |
| [Compiler Explorer](https://godbolt.org/) | Seeing how source code compiles across compilers, optimization levels, architectures, and language versions. Excellent for systems-oriented learning. |
