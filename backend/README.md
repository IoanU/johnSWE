# Backend Development

Modern, hands-on resources for learning how production backends work - from requests and APIs to authentication, state, caching, databases, and frameworks.

## Start here

| Resource | Description |
|---|---|
| [Backend Developer Roadmap](https://roadmap.sh/backend) | A clean map of the concepts worth knowing as a backend engineer, with links and checkpoints you can use to guide your learning. |
| [Backend Projects](https://roadmap.sh/backend/projects) | Project ideas that force you to apply backend concepts instead of only reading about them. |
| [FastAPI Interactive](https://www.fastapiinteractive.com/) | Free browser-based FastAPI course with interactive exercises backed by a real server. Covers APIs, validation, databases, auth, cookies, testing, async work, and more. |

## Authentication

| Resource | Description |
|---|---|
| [Auth0 Developer Labs](https://developer.auth0.com/resources/labs) | Hands-on authentication labs covering login flows, authorization, identity providers, APIs, and common application integrations. |
| [OAuth 2.0 Playground](https://oauth.net/playground/) | Interactive playground for understanding OAuth 2.0 flows such as Authorization Code + PKCE, Device Code, refresh tokens, and OpenID Connect. |
| [PortSwigger Authentication Labs](https://portswigger.net/web-security/authentication) | Free interactive labs that show how authentication mechanisms fail in real applications and how those mistakes can be recognized. |

## Sessions

| Resource | Description |
|---|---|
| [OWASP Session Management Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html) | Practical guide to session IDs, expiration, regeneration, transport security, fixation, logout, and secure session lifecycle design. |
| [PortSwigger Authentication Labs](https://portswigger.net/web-security/authentication) | Interactive exercises involving login state, persistent sessions, credential handling, and broken session-related behavior. |

## Cookies

| Resource | Description |
|---|---|
| [MDN - Using HTTP Cookies](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Cookies) | Clear modern guide to how cookies work, including `Secure`, `HttpOnly`, `SameSite`, expiration, scope, privacy, and security. |
| [FastAPI Interactive](https://www.fastapiinteractive.com/) | Includes executable browser exercises for receiving and working with cookies in a backend application. |

## Caching

| Resource | Description |
|---|---|
| [Redis University](https://redis.io/tutorials/university/) | Free hands-on Redis courses for learning caching, data structures, persistence, streams, and real application patterns. |
| [Caching Proxy Project](https://roadmap.sh/projects/caching-server) | Build a caching HTTP proxy yourself and learn cache hits, misses, expiration, forwarding, and invalidation through a concrete project. |

## Common frameworks

| Resource | Description |
|---|---|
| [FastAPI Interactive](https://www.fastapiinteractive.com/) | Learn a modern Python backend framework entirely through executable browser exercises. |
| [Spring Getting Started Guides](https://spring.io/guides/) | Short hands-on Java/Spring projects designed to get a working application running quickly instead of front-loading framework theory. |
| [ASP.NET Core Learning Path](https://learn.microsoft.com/en-us/training/paths/aspnet-core-web-app/) | Free Microsoft Learn path with guided modules and exercises for building web applications with ASP.NET Core. |

## Core concepts to understand

- request/response lifecycle and middleware
- REST, RPC, WebSockets, and API design
- authentication vs. authorization
- cookies, sessions, tokens, and JWTs
- validation and error handling
- database access, transactions, and connection pooling
- caching and cache invalidation
- background jobs and message queues
- configuration, secrets, logging, and observability
- rate limiting, retries, idempotency, and resilience
- testing and deployment

> Frameworks change. HTTP, state, databases, security, caching, and failure modes are the concepts that transfer between stacks.
