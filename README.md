# johnSWE

> A curated collection of free, high-quality resources for learning software engineering and computer engineering - without having to comment **“link”** under another Instagram Reel.

Use this repository to explore a new field, prepare for interviews, fill gaps in university coursework, or go deeper into a topic you already work with.

> [!NOTE]
> Some resources naturally overlap multiple areas, so you may see the same link in more than one guide. A few pre-existing resources have optional paid features; when that matters, it is called out explicitly.

## Start here

| Resource | Why it is useful |
| --- | --- |
| [roadmap.sh](https://roadmap.sh/) | Visual learning roadmaps for many software-engineering roles and technologies. |
| [QuickRef](https://quickref.me/) | Fast, searchable cheatsheets for languages, tools, commands, and frameworks. |
| [Exercism](https://exercism.org/) | Practice exercises and mentoring across dozens of programming languages; the core platform is free. |
