# System Design

Resources for learning how scalable systems are decomposed, how components interact, and how to reason about engineering trade-offs.

## Resources

| Resource | Best for |
| --- | --- |
| [System Design Primer](https://github.com/donnemartin/system-design-primer) | A comprehensive, open-source introduction to scalable-system concepts and common interview questions. |
| [ByteByteGo - System Design 101](https://github.com/ByteByteGoHq/system-design-101) | Visual explanations of common architecture patterns and infrastructure concepts. |
| [AlgoMaster - System Design](https://blog.algomaster.io/t/system-design) | Clear system-design articles and diagrams. **Note:** not every piece of content is free, so use the freely accessible material only. |

## Core topics

Learn requirements and capacity estimation, load balancing, caching, databases, replication, partitioning, queues, consistency, idempotency, rate limiting, CDN usage, observability, fault tolerance, and the trade-offs behind each choice.

A good system-design answer is not a list of technologies. It is a sequence of justified decisions tied to requirements and failure modes.
